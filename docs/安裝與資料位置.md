# 安裝與資料位置

## 下載的檔案

| 檔案 | 用途 | 程式資料與劇本預設位置 |
|---|---|---|
| `SceneForge-Setup-<版本>.exe` | Windows 安裝版：只安裝給目前使用者，不需要管理員權限，可改安裝位置，會建立桌面與開始功能表捷徑 | 資料庫、快照、垃圾桶、備份：`%LOCALAPPDATA%\SceneForge\data`；設定：`%LOCALAPPDATA%\SceneForge`；新劇本：`文件\SceneForge` |
| `SceneForge.exe` | Windows 免安裝版：放在任何可寫入的資料夾直接執行；更新時覆蓋同一個 exe 即可 | exe 同層的 `Data`（程式資料與設定）和 `Scripts`（劇本） |
| `SceneForge-<版本>-mac-arm64.dmg` | macOS（Apple Silicon）：打開後把 SceneForge 拖到「應用程式」 | 資料庫、快照、垃圾桶、備份與設定：`~/Library/Application Support/SceneForge`；新劇本：`~/Documents/SceneForge` |

三種版本功能相同，資料各自獨立。免安裝版的 `Data`、`Scripts` 會跟著 exe 所在的資料夾移動；如果 exe 旁邊無法寫入，程式資料會改存到使用者資料目錄。實際位置可以在程式的「資料存放位置」查看。另存的 `.sfe` 劇本可以放在任何地方。

SceneForge 不會自動更新、不檢查更新，也不收集任何使用資料。

## 第一次開啟

程式目前沒有數位簽章：

- **Windows**：如果出現「Windows 已保護您的電腦」，點「其他資訊 › 仍要執行」。
- **Mac**：如果被擋下，到「系統設定 › 隱私權與安全性」按「仍要打開」。如果顯示「已損毀」，在終端機執行 `xattr -cr /Applications/SceneForge.app` 後再開啟。

## 解除安裝

- **Windows 安裝版**：從「設定 › 應用程式」解除安裝。過程中會詢問是否一併刪除 `%LOCALAPPDATA%\SceneForge` 內的資料，預設為保留；覆蓋安裝新版本時不會刪除資料。`文件\SceneForge` 裡的劇本一律不會被刪除。
- **Windows 免安裝版**：直接刪除 exe；`Data`、`Scripts` 是否保留由你決定。
- **Mac**：把「應用程式」中的 SceneForge 移到垃圾桶。資料與劇本資料夾不會被自動刪除，需要時請先備份，再手動處理。
